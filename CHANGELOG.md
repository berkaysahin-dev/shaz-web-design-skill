# Changelog — Shaz Design System

All notable changes to this project are documented in this file in accordance with [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.1.0] — 2026-11-16
### Added
- **Multi-Editor & IDE Configuration Architecture:**
  - Native configuration presets for Cursor, Windsurf, VS Code, Claude Code, and GitHub Copilot.
- **Modular Core System (`core/`):**
  - `core/design-philosophy.md`: Swiss Utilitarian principles and layered architecture.
  - `core/mandatory-rules.md`: Non-negotiable architectural standards and visual constraints.
  - `core/industry-intelligence.md`: 8 sector DNA profiles with balanced light and dark mode surfaces.
  - `core/design-diversity.md`: Layout composition engine and creative direction tiers.
  - `core/reference-intelligence.md`: 12-axis semantic indexing and blueprint synthesis protocol.
  - `core/visual-quality.md`: 100-point visual quality matrix with an 85-point minimum threshold.
  - `core/accessibility.md`: WCAG AA standards, focus indicators, mobile ergonomics, and 60 FPS motion.
  - `core/capability-detection.md`: Environment adaptation and tool fallback matrix.
- **Native Editor Adapters (`adapters/`):**
  - `adapters/cursor/` (Native MDC rules and `.cursorrules`).
  - `adapters/claude/` (Claude Code configuration and CLI commands).
  - `adapters/codex/` (`AGENTS.md` standard specification).
  - `adapters/gemini/` (`GEMINI.md` workspace configuration).
  - `adapters/copilot/` (`.github/copilot-instructions.md`).
- **Automated Validation Suite:**
  - `scripts/validate-skill.js`: Structural and reference link validator.
  - `scripts/check-compatibility.js`: Cross-platform configuration checker.
  - `tests/compatibility/test-platform-adapters.ps1`: Platform test runner.

## [2.0.0] — 2026-11-16
### Added
- **Art Direction & Exploration System:**
  - 3-direction design exploration (*Safe & Premium*, *Bold & Distinct*, *Experimental*).
  - Expanded library to 1,008 production blueprints indexed in `library/INDEX.md`.
  - Visual Pattern Intelligence for heroes, navigation headers, feature showcases, and footers.
  - 100-point visual quality audit gate with 85-point delivery threshold.
  - Theme history tracking to guarantee cross-project aesthetic diversity.

## [1.2.0] — 2026-11-16
### Added
- **Editorial Layouts & Typography Refinement:**
  - Elimination of decorative kicker micro-labels above headings.
  - Human, concise copy standards (maximum 1 dense sentence per section).
  - Light-mode equal surfaces (Apple white and off-white precision).
  - 3 New Production Blueprints:
    - `02-navigation/floating-pill-capsule-nav.md` (Floating pill capsule nav with avatar and language selector).
    - `06-product-showcase/tech-stack-pill-marquee.md` (Continuous tech stack pill marquee).
    - `09-forms-footers/split-inquiry-email-composer.md` (Split dialogue inquiry with interactive email client card).
