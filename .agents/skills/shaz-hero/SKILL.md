# /shaz-hero — High-Cinematic Hero Section Generator

Use this skill when the user runs `/shaz-hero [brief or industry]` or asks for a premier hero section adhering to Shaz Agency standards.

## Mandatory Hero Guardrails:
1. **Headline Primacy:** Headline carries 80% of narrative weight. Zero eyebrow tags, category kickers, or overlines above titles (Law 2, Law 13).
2. **Strictly Backgroundless Focal Centerpiece:** Products, 3D specimens, HUDs, or execution telemetry must float directly on transparent canvas (`bg-transparent`), never inside double-layer boxes (`.bezel-tray` -> `.bezel-core`) or dark square cards (Law 8, Law 11, Law 14).
3. **Seeded Archetype & Centerpiece:** Hero archetype (Axis D) and visual centerpiece (Axis E) come from `rules/variation-engine.md`: typography only, inline SVG illustration, generative pattern, verified photography, a real data visual, 2D canvas, or a WebGL scene only when the subject is physical or spatial. Any backdrop media is text-free and supplied by the brief or generated (Law 7, Law 14).
4. **Calm Autonomous Kinematics:** Continuous smooth mechanical movement without chaotic cursor-tilt tracking or perspective wobbling (Law 11).
5. **Clean Exit:** No horizontal stat tickers or ticker strips glued underneath the hero (Law 9).

## Output Protocol (compact):
Run the Variation Engine first (`rules/variation-engine.md`). Print only the Design Signature (`SKILL.md` §5), then complete, executable, copy-pasteable code with zero placeholders. No essays, no list of laws.
