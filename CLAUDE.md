# Shaz Agency Web Design — Claude Code Adapter

This adapter configures Claude Code CLI (`~/.claude` or project root `CLAUDE.md`) to operate the Shaz Agency Web Design system with complete design intelligence, motion choreography, color consistency, and content integrity.

---

## 1. Mandatory Invariants (Enforced on Every Turn)

- **Zero Eyebrow Kicker Labels:** Never generate micro-tags, uppercase category labels, or counters directly above headings (e.g. `OTONOM SISTEMLER`, `01 · TEMEL`). Headings lead nakedly and authoritatively.
- **Global Content Integrity:** Strictly eliminate meaningless filler copy (`Küme sağlıklı`, `Sistem aktif`, `Yenilikçi yaklaşım`, `Geleceği şekillendiriyoruz`). Never generate fake status indicators or fictitious telemetry logs. Apply the Content Necessity Test to every text element.
- **Zero Heavy Essays & Academic Jargon:** Maximum 1 stylish, human sentence per section. Never write dense philosophical manifestos.
- **Global Color Consistency:** Define semantic color tokens upfront (`ground`, `surface`, `ink`, `muted`, `brand`, `accent`, `border`). Never introduce disconnected or ad-hoc hex colors in isolated components.
- **Global Motion & Tactile Quality:** Interactive elements must never be lifeless; they must feature purposeful, smooth motion (`translateY(-2px)`, active states, functioning tabs/filters). No fake buttons or non-working controls.
- **Zero Dark-Only Defaulting:** Light surfaces (Apple white `#FFFFFF`, clean off-white `#F5F5F7`, paper `#F7F6F2`) are first-class equals.
- **Zero Blinking & Pulsing Lights:** No `animate-pulse`, no flashing dots, no radar pings.
- **Zero Glow & Neon:** No fluorescent RGB drop-shadows or laser borders.
- **Zero Repeating Gradients & Cloned Bento Grids:** Break repetitive 3-card rounded patterns with asymmetric editorial compositions and horizon ledgers.
- **Zero Emojis:** Pure monochrome vector icons only (`lucide-react` or inline SVG).
- **Dynamic Container Metrics:** Use calibrated container widths (`max-w-2xl` to `max-w-7xl` / full-bleed); avoid forcing all sections into `max-w-5xl`.

## 3. Workflow & Output Protocol

1. **Step 1:** Establish Industry DNA (choose from the 10 sectors).
2. **Step 2:** Define Centralized Semantic Color Tokens & Layout-First Composition.
3. **Step 3:** Eliminate all filler microcopy using the Content Necessity Test.
4. **Step 4:** Synthesize at least 5 blueprints from `library/INDEX.md`.
5. **Step 5:** Perform the 15-Point Self-Audit and compute the Visual QA Score (must be ≥ 85/100).
6. **Step 6:** Output ONLY the **Design Signature** followed immediately by complete, unabridged, copy-pasteable Next.js / Tailwind CSS / Framer Motion code:

```markdown

- **Art Direction:** Layout [x] · Type [font pair] · Ground [hex] · Nav [archetype] · Hero [composition] · Container [dynamic scale]
```
