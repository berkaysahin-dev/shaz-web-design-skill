# Shaz Agency Web Design — 8-Point Anti-Template Diversity Gate Audit

Before any website architecture, design direction, or code generation begins in Shaz Agency Web Design, run this mandatory **8-point Anti-Template Diversity Gate**.

This gate ensures that the skill never defaults to carbon-copy AI landing page clichés:
- No habitual pitch-black obsidian backgrounds when daylight editorial palettes are appropriate.
- No automatic left-text/right-3D split heroes.
- No uninspired 3-card bento grids.
- No dogmatic `Hero -> Features -> Specs -> CTA -> Footer` section sequences.
- No arbitrary rotating 3D models where physical CSS typography or Zero-WebGL is superior.
- No universal Swiss CET clock footers on non-horological brands.

If any check fails, halt execution, reject the habitual pattern, and re-derive the design from the **Variation Engine** seed and the brief's concept artifact.

---

## The 8-Point Anti-Template Diversity Gate Checklist

| # | Check Item | Verification Command / Observation | Pass Criteria |
| :-: | :--- | :--- | :--- |
| **1** | **Chromatic Polarity & Materiality Check** | Inspect root tokens (`--bg-primary`, `--text-primary`, CSS root variables). Verify background and accent against sector materiality. | Palette is strictly derived from the brand's physical domain (e.g., Warm Sand `#F4EFEA` for Architecture, Clinical Alabaster `#F8F9FA` for Biotech, Deep Forest Soil `#1C241D` / Organic Oat `#F7F4EE` for Agriculture, Solar Flare `#0D0C15` for Space). **Automatic default to obsidian `#070709` is REJECTED** unless the brief explicitly calls for midnight luxury or astronomical voids. |
| **2** | **Hero Archetype Heterogeneity Check** | Inspect hero layout structure, viewport occupancy, and spatial grid. | Hero layout uses the hero archetype seeded on Variation Engine Axis D (one of the 6 archetypes of Law 20). **Habitual 50/50 split (left text block + right floating 3D canvas) is REJECTED** unless specifically validated by the 3-direction exploration. Alternative formats (Monumental Typographic Primacy, Asymmetric Monolith, Editorial Dossier Split, Full-Viewport Cinematic Stage) must be actively considered. |
| **3** | **Narrative Section Sequencing Check** | Trace the sequence of sections from hero to closing footer. | Section order is organically derived from the user's conversion/discovery psychology for the specific sector (e.g., Architecture: Hero -> Work Index -> Project Dossier -> Material Archive -> Practice Philosophy -> Salon Inquiry). **The generic `Hero -> 3 Feature Cards -> Specs -> Testimonials -> CTA` sequence is STRICTLY BANNED.** |
| **4** | **3D / WebGL Justification & Performance Check** | Inspect 3D canvas implementation, poly count, draw calls, and bundle footprint. | If WebGL is present, it must serve a functional storytelling purpose (e.g., mechanism exploration, real-time audio visualization, planetary data simulation, caustic glass dispersion). Max asset load < 15MB, guaranteed 60 FPS, and graceful CSS/SVG fallback. **If the project is editorial, biodynamic agriculture, or developer docs, ZERO-WEBGL is mandatory.** |
| **5** | **Navigation Archetype Alignment Check** | Verify navbar structure, pinned positioning, and responsiveness. | Navigation model matches the interaction ergonomics of the product (e.g., Minimal Corner Telemetry for architecture, Dual-Tier Utility Header for FinTech, Full-Bleed Editorial Banner for high fashion, Split Brutalist Bar for festivals). **Floating capsule dock is NOT applied universally**—only where mobile app-like compact floating navigation is stylistically warranted. |
| **6** | **Footer Telemetry & Geographic Authenticity** | Inspect footer coordinates, timekeeping widgets, and regulatory colophon. | Footer telemetry directly reflects the genuine geographic origin, real operational headquarters, or actual server telemetry of the brand. **Universal application of the Geneva CET clock or Swiss coordinates to non-horological, non-Swiss entities is STRICTLY BANNED.** |
| **7** | **Typographic Pairing Persona Check** | Audit primary display and text font families against the brand personality. | Font pairing captures the precise cultural nuance of the industry (e.g., Brutalist Display + Mono for electronic music; High-contrast Didone/Canela + Neo-Grotesk for luxury; Clean DIN / Technical Grotesk for engineering; Editorial Serif + humanist sans for organic food). Defaulting to Inter/Roboto or universally copying Druk Wide is prohibited. |
| **8** | **Content-Driven Component Architecture (Anti-Bento)** | Inspect card grids, data presentations, and narrative blocks across the page. | Layout containers are shaped by the exact nature of the information (e.g., asymmetric image dossiers, dense financial telemetry tables, full-bleed split photography, chronological interactive timelines). Carbon-copy 3-column bento boxes with identical padding and icons are rejected. |

## Verification Protocol: Directions Are Explored Internally

Consider three genuinely different directions **internally** (A: the sector's disciplined tradition · B: editorial/asymmetric · C: experimental/kinetic), seeded from `rules/variation-engine.md`. Do not print a comparison table — it spends the output budget that the complete code needs (`SKILL.md` §5). The result of this exploration appears in the Design Signature as the **Concept**, the **Seed** line (with any overrides and their reasons) and the **Defaults rejected** line.

If a check above fails, discard the failing choice, re-roll that axis (add 1 to S for that axis only) and re-run the gate.
