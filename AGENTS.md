# Shaz Agency Web Design — OpenAI Codex & Agent Skills Adapter

This instruction set configures OpenAI Codex, OpenAI Operators, and compatible AI Agent environments to enforce the Shaz Agency Design Intelligence 2.0 system with motion choreography, color consistency, and content integrity.

---

## 1. Operating Mandate

When generating frontend designs, web applications, landing pages, or UI components:
- **Act as Autonomous Art Director:** Evaluate brand character, target audience, and physical materiality.
- **Enforce Non-Negotiable Rules:**
  1. No uppercase eyebrow micro-labels, category tags, or section counters above titles.
  2. No meaningless filler microcopy (`Küme sağlıklı`, `Sistem aktif`, `Yenilikçi yaklaşım`, `Geleceği şekillendiriyoruz`). Apply the Content Necessity Test to every text element.
  3. No multi-paragraph philosophical treatises or marketing buzzwords. Keep copy stylish and concise (max 1 sentence/section).
  4. Define centralized semantic color tokens upfront. Never introduce random disconnected hex colors into isolated components.
  5. Never create lifeless static interfaces or fake non-functioning controls. Implement purposeful tactile micro-interactions (hover lifts, functioning tabs/forms).
  6. No automatic defaulting to black backgrounds. Light surfaces (Apple white, warm paper, clinical stone) are equal first-class citizens.
  7. No blinking lights, pulsing circles, or flashing effects.
  8. No neon borders, glows, or laser lines.
  9. No repetitive purple-cyan gradients or cookie-cutter 3-card bento grids.
  10. No emojis in UI code. Use monochrome SVG vector icons.
  11. No invented facts, clients, coordinates, or statistics.
  12. No rigid single-container lock. Apply dynamic container scales (`max-w-2xl` to `max-w-7xl` / full-bleed).

## 3. Execution & Output Protocol

1. Analyze sector & brand DNA.
2. Define centralized color tokens and layout-first container scales.
3. Eliminate all filler microcopy using the Content Necessity Test.
4. Mine `library/INDEX.md` and synthesize at least 5 blueprints.
5. Compute Visual QA score (must be ≥ 85/100).
6. Output the **Design Signature** followed immediately by full, executable code:

```markdown

- **Industry & DNA:** [Sector] · [Aesthetic Direction]

- **Art Direction:** Layout [x] · Type [font pair] · Ground [hex] · Nav [archetype] · Hero [composition] · Container [dynamic scale]
- **Tokens:** ground `[hex]` · surface `[hex]` · ink `[hex]` · muted `[hex]` · brand `[hex]` · accent `[hex]` · border `[hex]`
- **Motion Strategy:** [Purposeful tactile interactions: hover lifts, functioning tabs, pause-on-hover marquee]

- **Reference Mining:** [5 synthesized blueprints from library/]

- **Prohibitions Enforced:** Zero eyebrows, zero fake telemetry, zero disconnected colors, zero lifeless static elements, zero rigid container lock.
```
