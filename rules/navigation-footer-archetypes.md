# Shaz Agency Web Design — Navigation & Footer Archetypes

This guide expands the skill beyond the single "Scroll-Morphing Dock" and "Geneva Clock Footer" reflexes, providing calibrated archetypes matched to project hierarchy and sector tone.

---

## 1. Navigation Archetypes

Select the navigation structure that authentically serves the project's reading flow:

| Archetype | Real Blueprint ID / File | Best For | Visual Anatomy | Prohibited When |
| :--- | :--- | :--- | :--- | :--- |
| **1. Scroll-Morphing Floating Dock** | `02-navigation/scroll-morphing-dock-navbar.md` | Single-page product launches, high-interaction tech apps, compact luxury showrooms. | Spans full-width at top; morphs into centered floating pill (`rounded-full`) with monochrome icon array at `scrollY > 80px`. | Documentation hubs, editorial newspapers, multi-level e-commerce catalogs. |
| **2. Editorial Masthead & Journal Header** | `02-navigation/minimal-overlay.md` (Variant A) | Cultural journals, literary reviews, fashion magazines, architectural monographs. | Fixed top edge-to-edge rule, bold serif publication title, volume number, issue date, and subtle right-aligned section links. | High-velocity developer platforms, interactive game portals. |
| **3. Minimalist Architectural Island** | `02-navigation/minimalist-double-bezel-nav.md` | Architecture studios, industrial furniture, sculpture portfolios. | Centered compact double-bezel island floating at `top-6`, housing only 3–4 minimalist routes with zero status badges. | E-commerce stores with multi-category mega menus. |
| **4. High-Density Command Bar** | `14-name-that-ui-dictionary/command-palette.md` | FinTech data terminals, developer cloud platforms, AI infrastructure. | Single hairline bar with active system health telemetry, breadcrumb path, and `⌘K` quick search trigger. | High-end luxury perfumes, artistic photography. |
| **5. Fullscreen Kinetic Overlay Trigger** | `14-name-that-ui-dictionary/hamburger-menu.md` (Variant B) | Avant-garde festivals, experimental music, high-impact fashion campaigns. | Header has only brand wordmark and an oversized brutalist "INDEX +" button; clicking opens full-screen typography takeover. | Utility SaaS platforms, corporate dashboards. |

## 2. Footer Archetypes

Never copy the same footer pattern between unrelated industries:

| Archetype | Real Blueprint ID / File | Best For | Key Visual Components | Prohibited When |
| :--- | :--- | :--- | :--- | :--- |
| **1. Haute Horlogerie Atelier Closing** | `09-forms-footers/bespoke-luxury-atelier-footer.md` | Luxury watch manufactures, private diamond ateliers, bespoke instrument makers. | Real-time Geneva CET clock (`Europe/Zurich`), salon addresses, Poinçon de Genève serial registry check, monumental brand watermark. | **STRICTLY BANNED** on SaaS, music festivals, food brands, and medical apps. |
| **2. Editorial Split Statement Footer** | `09-forms-footers/editorial-split-footer.md` | Architecture practices, design consultancies, cultural institutions. | 50/50 vertical split: Left side features a commanding design manifesto sentence; Right side features direct principal partner email and salon cities. | High-volume consumer retail stores. |

| **5. Agricultural Terroir & Provenance Footer** | `rules/section-composition-engine.md` (Archetype 5) | Biodynamic wine estates, organic food, regenerative agriculture. | Farm geographic coordinates, seasonal harvest calendar, cellar visiting hours, organic soil certification hallmark. | Software developer tools, tech startups. |

## 3. The Geneva Clock Proscription

> **CRITICAL RULE:** The real-time Geneva CET clock (`Europe/Zurich`) is an exclusive signature of Haute Horlogerie (Swiss watchmaking). 
> It is **STRICTLY PROHIBITED** to copy this clock into non-horological domains such as music festivals, organic agriculture, cloud software, or general agencies. Replace it with the domain's authentic live telemetry:
> - Music Festival: **Live Countdown to Doors Opening** or **Current Stage Set Time**.
> - Architecture Studio: **Studio Timezone Matrix** (e.g. Zurich 14:00 · Tokyo 22:00 · New York 08:00).
> - Cloud Infrastructure: **API Global Edge Status** (e.g. P99 Latency: 42ms · 100% Operational).
> - Organic Food: **Current Season & Harvest Window** (e.g. Autumn Pressing · 12 Days Remaining).
