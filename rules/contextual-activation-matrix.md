## 2. Project Design Signature Protocol (Mandatory Before Coding)

Every implementation MUST declare its **Project Design Signature** in the design plan:

```markdown
### PROJECT DESIGN SIGNATURE
1. **Target Archetype:** [e.g. Archetype 5: Organic Earth & Sustainable Agriculture]
2. **Chromatic Polarity:** [e.g. Light Natural Kraft #F5F2EB with Forest Olive #2C362B]
3. **Typography Character:** [e.g. Instrument Serif + Plus Jakarta Sans]
4. **Hero Architecture:** [e.g. Split Terroir with Harvest Coordinates, Zero 3D]
5. **Section Sequence:** [e.g. Provenance Bar -> Terroir Hero -> Soil Telemetry -> Seasonal Ledger -> Farmer Almanac -> Terroir Footer]
6. **Navigation Model:** [e.g. Editorial Harvest Masthead]
7. **Footer Model:** [e.g. Agricultural Terroir & Season Seal (Zero Geneva Clock)]
8. **3D/WebGL Stance:** [e.g. Strictly Zero WebGL - Physical materiality through high-res photography and CSS paper grain]
9. **Deliberately Rejected Defaults:** [e.g. Rejected dark obsidian #070709, rejected scroll-morphing dock, rejected rotating 3D model, rejected Geneva CET clock]
```

## 3. Component Selection Rules (Breaking Component Monotony)

### 3.1 Navigation Selection
* If site is **Editorial / Magazine / Journal:** Deploy `Editorial Masthead`.
* If site is **Minimalist Studio / Architecture:** Deploy `Minimalist Double-Bezel Island`.
* If site is **Developer Platform / Quant FinTech:** Deploy `High-Density Command Bar` with `⌘K`.
* If site is **Music Festival / Avant-Garde:** Deploy `Fullscreen Kinetic Overlay Trigger`.
* Deploy `Scroll-Morphing Floating Dock` **ONLY** for high-interaction product showcases or compact single-objective launches.

### 3.2 3D / WebGL Decision Gate
* Ask: *Does this brand represent physical spatial engineering, optics, or cosmic scale?*
  - **YES:** Select 1 matching blueprint from `library/05-3d-webgl/` (e.g. `wave-galaxy.md` for cosmos, `cad-wireframe-inspector.md` for aerospace, `analog-mechanism.md` for watches).
  - **NO (e.g. Food, Editorial, Law, Logistics):** Enforce **Zero WebGL**. Use high-definition photography, typography scale, and SVG data tables.

### 3.3 Micro-Interaction Selection (Code & Chill)
* For quantitative / telemetry data: Use `sub-pixel-counter-reveal.md` or `odometer-roll-up.md`.
* For case-study portfolios: Use `sticky-monograph-stack.md` or `horizontal-case-study-slider.md`.
* For typography / creative weight manipulation: Use `interactive-glyph-scrubber.md`.
* Never apply identical spring parameters across all sites:
  - Technical / Quant: Tight, rapid springs (`stiffness: 340, damping: 30`).
  - Luxury / Horology: Calm, deep springs (`stiffness: 260, damping: 26`).
  - Organic / Editorial: Smooth cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`), minimal bouncy springs.
