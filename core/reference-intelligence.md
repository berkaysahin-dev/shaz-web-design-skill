# Shaz Agency Web Design — Reference Intelligence & Blueprint Synthesis

The reference library (`library/`) contains **1008 production-grade blueprints** indexed in `library/INDEX.md`. It is an active architectural knowledge bank, not an archival dump.

---

## 1. 12 Semantic Indexing Axes

Every blueprint in the library is indexed across 12 analytical dimensions:
1. **Industry:** Sector applicability (SaaS, Architecture, FinTech, Hospitality, etc.).
2. **Design Style:** Aesthetic lineage (Swiss Utilitarian, Neobrutalism, Editorial, Bento, Spatial).
3. **Color Palette:** Ground, surface, ink, and accent tokens.
4. **Typography:** Font pairings, optical scales, and line-height calibration.
5. **Hero Composition:** Layout mechanics of the primary viewport.
6. **Layout Structure:** Full-page grid, pacing, and section rhythmic cadence.
7. **Navigation:** Header archetype and responsive mobile behavior.
8. **Section Patterns:** Feature presentation, services, testimonials, and case studies.
9. **Animation Approach:** Spring physics, scroll-linked parallax, inertia, and Lerp kinematics.
10. **Spacing:** Container widths, gutters, and vertical breathing room (120px–180px).
11. **Component Architecture:** Card structures, drawers, tabs, and interactive widgets.
12. **Visual Hierarchy:** Dominant focal points, contrast ratios, and read paths.

---

## 2. Mandatory 5-Reference Synthesis Protocol

When conceptualizing any project or section:
1. **Search `library/INDEX.md`:** Run a semantic search for relevant blueprints matching the sector and requirements.
2. **Select at least 5 distinct blueprints:**
   - E.g. 1 for Navigation (`02-navigation/...`)
   - 1 for Hero composition (`01-hero-sections/...` or `17-cinematic-heroes/...`)
   - 1 for Feature showcase (`06-product-showcase/...` or `22-sections/...`)
   - 1 for Interactive motion / component (`10-interactive-animations/...` or `24-dqnamo-kitchen/...`)
   - 1 for Form / footer (`09-forms-footers/...`)
3. **Extract Mechanics, Discard Demo Skin:**
   - Extract the physical interactions, spring physics, and grid structure.
   - Discard the blueprint's demo text, mock brands, and colors.
   - Inject the project's authentic brief content, brand palette, and typography.
4. **Strict Reference Authenticity:**
   - Every reference cited in the Design Signature MUST exist in `library/`. Zero phantom or fabricated blueprint paths.
